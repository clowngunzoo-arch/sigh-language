# Handly

Sign language (ASL) to text: fingerspelling, built-in words, your own recorded signs, and video calls with live captions.

## Run locally
1. Open this folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html` and choose **Open with Live Server**.

## Files
- `index.html` - page structure
- `style.css` - styling
- `app.js` - camera, sign rules, recorded signs, video call
- `manifest.json`, `sw.js`, `icon-*.png`, `logo.svg` - install-as-app (PWA) and logo
